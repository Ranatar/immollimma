## Темы и персонажи

- Узник-звезда: тёплый золотой напев альтовой флейты и солирующей скрипки — E F B C (полутоны и тритон); загорается в 8.1 → рвётся в 52.8 → вспыхивает при приказе → гаснет точкой в 89–90
- Легион: квинтовый аккорд, по звуку на ряд, от верхних (дальние ряды) к нижним (ближние); собирается 31–40 с → держится → распадается снизу вверх при уходе 59–70 с
- Повелитель: пять квинт меди, по глифу имени; 48–52.8, держится до приказа

## Решения (правка плана вручную)

Без голосов и хора: у некронов нет душ. Орган — только как чистый субтон, не церковный тембр.

**Сквозные процессы.**
- Квинтовая стопка C–G–D–A–E–B–F♯ собирается и разбирается: рёбра и обереги (II) → легион по рядам (VI) → имя (VII) → приказ (IX) → распад снизу вверх (X) → обратный порядок (XI)
- Сердце: accelerando 21–28.8, затем ровно каждые 1,2 с до приказа
- Тиканье: в начале — точно по сменам разряда счётчика, замедляясь до остановки; в конце — заново с нуля

**Лейтмотивы.**
- Узник-звезда: E5 F5 B4 C5 (альтовая флейта, солирующая скрипка) — тепло среди холода
- Повелитель: C3 G3 D4 A4 E5 — пять квинт меди
- Легион: по звуку на ряд: F♯5 B4 E4 A3 D3 G2 C2, затем удвоения в басу
