# immollimma

Комплект для сочинения оркестровой музыки Claude: партитура как код, настоящие семплы (VSCO-2 CE,
Sonatina), ноты, отчёт приборов. Порядок работы — `.claude/skills/immollimma/SKILL.md` (прочти целиком
перед любым музыкальным заказом). Вкус заказчика — `taste.md` (читать первым). Грабли — `docs/pitfalls.md`.

- Общение и документы — по-русски; новые идентификаторы в коде — латиницей.
- Коммиты — под `Ranatar <sheogorath2006@gmail.com>`, без трейлеров Co-Authored-By / Claude-Session.
- Библиотеки семплов — в `libs/` (не в git), ставятся `sh tools/setup.sh`.
- После правок `kit/` — `sh tools/selftest.sh`.
